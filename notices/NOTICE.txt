This package contains a modified build of SmartTube
(https://github.com/yuliskov/SmartTube), Copyright (c) 2020-present yuliskov,
distributed under the MIT License (SmartTube-LICENSE.txt).

Built from the official armeabi-v7a release APK, unmodified except for:
  - AndroidManifest.xml: adds the android.permission.GET_TASKS permission
  - NetworkData.isConscryptEnabled() always returns true
  - the update_urls resource points at this project's releases (or is empty)
  - versionCode is upstream's versionCode * 100 + this project's revision
  - MotherActivity.initEdgeSlide() enables the left-edge swipe (Slidr) on
    Android 4.4 instead of only 5.0+
  - Slidr's SliderPanel gets an onLayout that keeps the swipe offset while a
    swipe is in progress
  - MotherActivity.onCreate() calls a new class, org.gen5w.DrivingGuard,
    which closes SmartTube when the head unit's regulation service reports
    the car out of park; adds the com.hkmc.permission.AUTOMOTIVE_REGULATION
    permission
  - MotherActivity lifecycle and ExoPlayer legacy audio-focus calls use a small
    API-19 helper to retain focus during internal navigation, releasing on exit
  - OkHttp API calls and ExoPlayer HTTP opens check fresh per-app guard state
  - a one-time Wi-Fi/BlueLink network notice is shown
  - the NEMESIS service pins this UID's Android 4.4 DNS to Wi-Fi and filters
    app and proxied DNS traffic for both IP families
and re-signed with this project's key.

Third-party libraries inside the APK are distributed by upstream under their
own licenses, unchanged.

The network guard and network-state rule adapt the Jellyfin on GEN5W wrapper
(https://github.com/ntwm787/Jellyfin-on-GEN5W), Copyright (c) 2026 Gen5W
Jellyflix wrapper contributors, MIT licensed (Jellyfin-wrapper-MIT.txt).
